Set permanent hostnames
```
sudo hostnamectl set-hostname lb-01.k8s.corp.example
```

Verify both load balancer servers:
```
hostnamectl
ip -br addr
ip route
getenforce
sudo firewall-cmd --get-active-zones
```
Install HAProxy and Keepalived
```
sudo dnf install -y haproxy keepalived policycoreutils-python-utils
```
Check the installed versions:
```
haproxy -v
keepalived --version
```
Prepare the HAProxy configuration
On both servers, back up the existing configuration:
```
sudo cp -a /etc/haproxy/haproxy.cfg \
  /etc/haproxy/haproxy.cfg.bak
```
Now write the configuration:
```
sudo tee /etc/haproxy/haproxy.cfg > /dev/null <<'EOF'
global
    log /dev/log local0
    log /dev/log local1 notice
    chroot /var/lib/haproxy
    stats socket /run/haproxy/admin.sock mode 660 level admin
    stats timeout 30s
    user haproxy
    group haproxy
    daemon

defaults
    log global
    mode tcp
    option tcplog
    option dontlognull
    timeout connect 5s
    timeout client  1m
    timeout server  1m

frontend kubernetes_api
    bind *:6443
    mode tcp
    default_backend kubernetes_control_plane

backend kubernetes_control_plane
    mode tcp
    balance roundrobin
    option tcp-check
    default-server inter 3s fall 3 rise 2

    server cp1 192.168.1.76:6443 check
    server cp2 192.168.1.77:6443 check
    server cp3 192.168.1.78:6443 check
EOF
```
Validate the configuration:
```
sudo haproxy -c -f /etc/haproxy/haproxy.cfg
```
note: Expected output should indicate that the configuration file is valid.

SELinux and port 6443:If port 6443 is not already permitted for HAProxy's listening-port policy, configure the appropriate SELinux port mapping. For a typical RHEL HAProxy setup, http_port_t is used:
```
sudo semanage port -l | grep -E 'http_port_t|6443'
sudo semanage port -a -t http_port_t -p tcp 6443
```
Allow HAProxy and VRRP through firewalld
On both load balancers:
```
sudo firewall-cmd --permanent --zone=public --add-port=6443/tcp
sudo firewall-cmd --permanent --zone=public --add-protocol=vrrp
sudo firewall-cmd --reload
```
Verify:
```
sudo firewall-cmd --zone=public --query-port=6443/tcp
sudo firewall-cmd --zone=public --query-protocol=vrrp
```


Create the HAProxy health-check script
On both servers:
```
sudo tee /usr/local/sbin/check_haproxy.sh > /dev/null <<'EOF'
#!/bin/bash
/usr/bin/systemctl is-active --quiet haproxy
EOF
```
```
sudo chown root:root /usr/local/sbin/check_haproxy.sh
sudo chmod 750 /usr/local/sbin/check_haproxy.sh
```

Configure Keepalived on LB-01
On 192.168.1.73, create /etc/keepalived/keepalived.conf:
```
sudo tee /etc/keepalived/keepalived.conf > /dev/null <<'EOF'
global_defs {
    router_id LB01
    enable_script_security
    script_user root
}

vrrp_script chk_haproxy {
    script "/usr/local/sbin/check_haproxy.sh"
    interval 2
    timeout 2
    fall 2
    rise 2
    weight -60
}

vrrp_instance VI_K8S_API {
    state MASTER
    interface enp1s0
    virtual_router_id 51
    priority 150
    advert_int 1

    unicast_src_ip 192.168.1.73
    unicast_peer {
        192.168.1.74
    }

    authentication {
        auth_type PASS
        auth_pass K8sVRRP1
    }

    virtual_ipaddress {
        192.168.1.75/24 dev enp1s0
    }

    track_script {
        chk_haproxy
    }
}
EOF
```

Validate and start the services
First, on both load balancers, validate HAProxy and Keepalived:
```
sudo haproxy -c -f /etc/haproxy/haproxy.cfg
sudo keepalived --config-test \
  --use-file=/etc/keepalived/keepalived.conf
```
Then enable and start HAProxy on both:
```
sudo systemctl enable --now haproxy
sudo systemctl status haproxy --no-pager
```

Check the listener:
```
sudo ss -lntp | grep ':6443'
```
Do not proceed to Keepalived until HAProxy starts successfully.

Next, start Keepalived on LB-02 first:
```
sudo systemctl enable --now keepalived
sudo systemctl status keepalived --no-pager
```
Then start it on LB-01:
```
sudo systemctl enable --now keepalived
sudo systemctl status keepalived --no-pager
```
Verify the VIP and failover
On both servers, run:
```
ip -br addr show enp1s0
```
Test the VIP from either load balancer:
```
ping -c 3 192.168.1.75
```

Run these on both load balancers
```
sudo systemctl is-active haproxy
sudo systemctl is-active keepalived
ip -br addr show enp1s0
sudo journalctl -u keepalived -n 30 --no-pager
```



Note:-

Fix the HAProxy configuration on both servers
The simplest fix is to remove the optional administrative socket configuration. We don't need that socket for the basic Kubernetes API load balancer.

On both LB-01 and LB-02, run:
```
sudo cp -a /etc/haproxy/haproxy.cfg \
  /etc/haproxy/haproxy.cfg.pre-socket-fix

sudo sed -i '/stats socket \/run\/haproxy\/admin.sock/d' \
  /etc/haproxy/haproxy.cfg
```
Verify the socket line is gone:
```
sudo grep -n 'stats socket' /etc/haproxy/haproxy.cfg
```
Validate the configuration
Run on both servers:
```
sudo haproxy -c -f /etc/haproxy/haproxy.cfg
```
Start HAProxy
On both LB-01 and LB-02:
```
sudo systemctl restart haproxy
sudo systemctl enable haproxy
sudo systemctl status haproxy --no-pager
```
